# 📊 Unemployment Analysis in India

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Unemployment in India dataset. The goal is to understand unemployment trends across different states, rural and urban areas, and analyze the impact of time on unemployment rates using Python.

---

## 🎯 Objectives

- Analyze unemployment trends in India
- Compare Rural and Urban unemployment rates
- Handle missing values
- Perform Exploratory Data Analysis (EDA)
- Identify outliers and data distribution
- Analyze correlations between numerical features
- Visualize important insights using charts

---

## 📂 Dataset Information

- Dataset: Unemployment in India
- Records: 741
- Features:
  - Region
  - Date
  - Frequency
  - Estimated Unemployment Rate (%)
  - Estimated Employed
  - Estimated Labour Participation Rate (%)
  - Area

---

---

## 📊 Data Analysis Performed

- Data Cleaning
- Missing Value Handling
- Date Formatting
- Histogram
- Box Plot
- Scatter Plot
- Correlation Heatmap
- Rural vs Urban Analysis
- Outlier Detection

---

## 📈 Key Insights

- Most unemployment rates are between 0–10%.
- Urban unemployment is slightly higher than Rural unemployment.
- Several outliers were observed during the COVID-19 period.
- No strong correlation exists between Labour Participation Rate and Unemployment Rate.
